# 🧪 Mujahid Labs (Development & Automation Repository)

Welcome to **mujahid-labs**! This repository serves as a centralized collection of my core development labs, web scrapers, automated business tools, and specialized scripts built using Python and various frameworks.

---

## 📂 Repository Structure & Overview

Inside this repository, you will find the following specialized project modules:

### 1. 📄 [Form16-Data-Extractor](./Form16-Data-Extractor)
* **Description:** A smart automation tool designed to extract critical financial, tax, and registration data from **Form 16 (TDS Certificate) PDFs**.
* **Tech Stack:** Python, `pdfplumber`, Regex (Regular Expressions).
* **Key Highlight:** Completely bypasses brittle index indexing, dynamically locating Employer/Employee PAN, TAN, Assessment Year, Gross Salary, and Total TDS Deducted using exact text-pattern matching.

### 2. 🌐 [Grocery-Data-Scrapers](./Grocery-Data-Scrapers)
* **Description:** High-efficiency data mining tools engineered to fetch live e-commerce inventory data.
* **Tech Stack:** Python, `requests`, `BeautifulSoup4`.
* **Key Highlight:** Features an internal API backend scraper targeting high-volume retail listings (like JioMart) to cleanly construct complete tabular exports (`.csv`) without trigger restrictions or parsing blocks.

### 3. ⚙️ [odoo](./odoo)
* **Description:** Custom modules, styling adjustments, and framework enhancements developed for the **Odoo ERP Framework**.
* **Key Highlight:** Focuses on business reporting, advanced report UI/UX styling, QWeb template custom workflows, and optimizing database management records.

### 4. 🗂️ [batScript](./batScript)
* **Description:** Windows batch scripts (`.bat`) utilized for native system task scheduling, workspace preparation, and automated background adjustments.
